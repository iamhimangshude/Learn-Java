# Object Oriented Programming in Java

## What are objects?
An object in Java are fundamental block of code that have both properties (data) and methods (behaviors).

## What are classes in Java?
A class in java is a blueprint or template that provides the architecture about how an object should be, what properties it should have and what behaviors it should be be able to perform.

## What is a main() method in Java?

A `main()` method in Java is special method which acts as an entry point function that calls other method or performs operations declared within the method body, it is a required method as JVM looks for this special method
